# 🎥 Universal Screen Recorder

**Works on Windows 7, 8, 10, 11 (32-bit and 64-bit)**

## ✨ Features

- **Real-time Drawing Overlay** - Draw directly on your screen
- **Auto Zoom to Active Window** - Zooms into the window you're using
- **Mouse Click Animations** - Visual ripple effects on every click
- **Mouse Click Sounds** - Audio feedback on every click
- **Universal Compatibility** - Works on all Windows versions
- **Lightweight** - Single .exe + FFmpeg

## 📥 Installation

1. Download the ZIP file from GitHub Actions
2. Extract it to any folder
3. Run `UniversalRecorder.exe`

## 🎮 Controls

- **LEFT click** - Creates ripple animation + sound
- **Hold LEFT + drag** - Draw on screen (when drawing mode is ON)
- **Clear All** - Erases all drawings

## 🔧 Requirements

- Windows 7 SP1 or later
- .NET Framework 4.7.2 (pre-installed on Windows 10+)
- FFmpeg (included in the download)

## 📝 Notes

- Recordings are saved to your Videos folder
- Drawings appear in the final video
- Auto-zoom captures the active window
